# Data directory

Datasets and cached feature tensors are intentionally excluded from Git because of their size.

Expected layout:

```text
data/
├── MNIST/                          # created automatically by Torchvision
├── cifar-10-batches-py/            # created automatically by Torchvision
├── tiny-imagenet-200/              # manual Tiny ImageNet download/extraction
└── features/
    ├── MNIST/<model>/
    ├── CIFAR10/alexnet/
    ├── TINYIMAGENET/alexnet/
    └── k_center_cache/              # generated by the KCG experiments
```

For each cached representation, the feature-extraction pipeline writes:

```text
train_features.pt
train_labels.pt
test_features.pt
test_labels.pt
metadata.json
```

Generate these artifacts with `extract_features.py` or `scripts/slurm/extract_features_slurm.sh`. The cached neural representations and KCG distance matrices occupy tens of gigabytes and should remain outside normal Git version control.
